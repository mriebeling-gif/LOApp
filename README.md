# LOApp – Tank vs UFOs (Three.js)

A small 3D browser game built with Three.js where you drive a tank and shoot down UFOs.

## How to run

Because this app uses JavaScript modules, run it from a local web server:

```bash
python3 -m http.server 5173
```

Then open:

- `http://localhost:5173`

## Controls

- **Move tank:** `WASD` or Arrow keys
- **Aim turret:** mouse cursor
- **Shoot:** Spacebar or left mouse click
- **Restart after game over:** click the Restart button
