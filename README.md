# LOApp / OpenTrace

A lightweight reverse-lookup web app inspired by people-search workflows.

## Features
- Reverse search modes for phone, name, email, and address.
- Curated open-source/public-source links per search mode.
- UI that generates actionable investigation links and structured search context.
- Clear lawful-use disclaimer.

## Run locally
```bash
python -m http.server 8080
```
Then visit `http://localhost:8080`.

## Notes
This project does not scrape protected systems or bypass terms; it helps users pivot through publicly available records and search engines.
